# 部活筋トレ管理アプリ

部員の筋トレ記録・MAX・体重をまとめて管理するWebアプリ。
名前を選ぶだけで使える（パスワードなし）。入力できる部員（選手）と閲覧のみ（マネージャー・監督など）を分けて登録する。

- トレーニング記録は筋トレMEMO風の**セット単位入力**（1セット目 60kg×10回、＋セットを追加…）
- MAX測定の対象種目は**スクワット・パワークリーン・ベンチプレス**の3つに固定
- MAX×KPIグラフのKPIは**月間セット数／月間トン数（重さ×回数の合計）／体重**。集計対象は「この種目のみ／全種目」を切替可
- 部員に**ポジション属性**（Lines / Backs / Skills）と**学年**（1〜4年）。グラフ・ランキングはポジション/学年で段階絞り込み可
- 体重・MAXグラフは**グループ表示**（ポジション・学年ごとの各個人の線＋平均の太線）に切替可
- MAXは**怪我（測定なし）**として記録可能。個人グラフでは怪我の月に🩹ラベルが付き、値は前回MAXを引き継ぐ（ランキングからは除外）
- MAX・体重・目標はフォーム内で部員を切り替えて**連続一括入力**できる（トレーナー向け）。名前の切り替えはヘッダー右上のドロップダウンからどのページでも可能
- **月末目標**（体重・MAX3種目）を各自が設定（記録する→🎯目標タブ）。ホームは目標ダッシュボード: 目標体重との差ランキング（TOP5＋下位5）とポジション別の差の平均バー
- 記録ページに**「今日の実施メニュー」**を表示（保存すると即時反映）
- 記録一覧は**本人の記録が基本**（トレーニング / MAX / 体重のタブ切替）。全員分は `/records/all`「みんなの記録」に分離
- **月次レポートCSV**: 部員全員の目標×実績（体重・MAX3種目・達成○×・怪我）をホームからダウンロード（`/api/report?month=YYYY-MM`、Excel対応BOM付きUTF-8）
- トレーニング記録は**部位**（脚・背中・胸・肩・腕・体幹）必須。個人の記録一覧に直近4週の部位別セット数表、みんなの記録に部員×週のトレーニング回数表（全体管理）
- PCはヘッダーナビ、スマホは画面下タブナビのレスポンシブ対応

## 起動方法

```bash
npm install
npx prisma db push   # 初回のみ: SQLiteのDBを作成
node prisma/seed.mjs # 任意: デモデータ投入（DBが空のときだけ動く）
npm run dev          # http://localhost:3000
```

## アクセス制限（部員のみ）

チーム共通パスワード方式。`proxy.ts` が全ページ・APIを保護し、未認証は `/login` へリダイレクトされる。
正しいパスワードを入れるとクッキーで半年間有効。

- パスワードは `.env` の `TEAM_PASSWORD`（**本番デプロイ時はVercelの環境変数に強いパスワードを設定して変更すること**）
- パスワードを変更すると全員再ログインになる（漏れた場合はこれで締め出せる）

## ページ構成

| ページ | 内容 |
|---|---|
| `/` | 目標ダッシュボード（目標体重との差ランキング・ポジション別平均）＋名前選択 |
| `/log` | トレーニング（セット単位） / MAX / 体重 / 🎯月末目標の入力（入力権限のみ）。今日の実施メニューも表示 |
| `/charts/max` | MAXの伸び × KPI（月間セット数・月間トン数・体重）の相関グラフ。部員・種目・KPI・集計対象・期間で絞り込み |
| `/charts/weight` | 体重推移グラフ。部員・期間で絞り込み |
| `/records` | 本人の記録一覧（トレーニング / MAX / 体重タブ）。MAXタブには部内ランキングも表示 |
| `/records/all` | みんなの記録: 全員のトレーニング記録を横断表示（部員・種目で絞り込み） |
| `/members` | 部員の登録・一覧（入力可 / 閲覧のみ） |

## 技術構成

- Next.js 16 (App Router) + TypeScript
- Prisma 6 + SQLite（`prisma/dev.db`）
- Recharts（グラフ）

## 部全体に公開するには

現状はローカル1台で動く構成。部員全員がスマホから使えるようにするには:

1. [Vercel](https://vercel.com) に無料アカウントを作り、このリポジトリをデプロイ
2. SQLiteはVercelでは使えないため、DBを [Supabase](https://supabase.com) か [Neon](https://neon.tech)（どちらも無料枠あり）のPostgresに変更
   - `prisma/schema.prisma` の `provider = "sqlite"` を `"postgresql"` に変え、`DATABASE_URL` を接続文字列に差し替えて `npx prisma db push`
3. 発行されたURLを部のLINEグループなどで共有

## 運用メモ

- 「名前選択だけ」の簡易方式なので、悪意ある部員がいる前提のセキュリティはない。部内利用限定を想定
- デモデータを消して本運用を始めるには `prisma/dev.db` を削除して `npx prisma db push` し直し、`/members` から実際の部員を登録する
